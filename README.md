# Aroma Beans Chatbot

Chatbot demonstrativo desenvolvido em React para o atendimento de uma cafeteria fictícia. Responde dúvidas sobre cardápio, horários, localização, contato e preparo de café.

## Funcionamento

- Respostas locais para as perguntas mais comuns, sem depender de chave pública.
- Integração externa opcional por meio da variável `VITE_API_URL`.
- Publicação automática no GitHub Pages.

## Desenvolvimento

```bash
npm install
npm run dev
```
